# Example project: Body to Body

Reference materials for the flagship example film (the 190s master
timeline in `src/remotion/timeline.ts`):

- `body-to-body.mp3` — the song the master timeline is cut to. The
  runtime copy lives at `public/audio/body-to-body.mp3` (Remotion's
  `staticFile` needs it under `public/`); this folder holds the
  reference original.
- `body_to_body.lrc` — synced lyrics; SCRIPT.md beat timings cite it.
- `yournamevertical.jpg` — visual reference for the homage scenes.

These are rights-holder materials kept for the example project — see
PUBLISHING.md before making the repository public.
